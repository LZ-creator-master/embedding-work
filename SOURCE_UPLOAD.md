# Source upload

This repository contains the source code and Markdown documentation from the local `embedding work` project. Dataset files, generated plots, PDF reports, archives, Python caches, and nested Git history are not included.

The 27 Python files passed syntax parsing before upload. Full experiments and dependency installation have not been validated. Some original README instructions are outdated; consult the actual configuration and entry-point code.

The `sude_official` reference sources originate from https://github.com/ZPGuiGroupWhu/sude . Original author notices are retained. No new license is assigned to third-party code by this upload. For the upstream data and complete repository, consult that project.

Neuron experiments require the original `swc_data` files. Other experiments may download data or require local data and separately installed dependencies, including SUDE. Existing local files were not modified.
